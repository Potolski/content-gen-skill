# Risein — "Build on Solana" — Structural Capture

> **Provenance:** https://www.risein.com/courses/build-on-solana (login-gated,
> video-based platform). This file is a **structural + pedagogical capture** of the
> public course outline, not a verbatim copy of video/lesson content. It gives the
> `META.md` analysis a stable artifact to reason over.

## Format
- **Delivery:** on-demand **video** lessons on a hosted learning platform (account
  required to watch). ~**6 hours** of total video across the course.
- **Scale:** **5 sections, 22 lessons.** Explicitly "self-paced" but "built to be
  done in order."
- **Model:** **project-based** — concept primer, then three scaffolded build
  projects of increasing complexity, then an independent capstone.

## Pedagogical signature
- **Foundational → practical trajectory:** a conceptual section first (transactions,
  instructions, accounts, PDAs), then immediately into building.
- **Scaffolded project ladder:** three guided projects (Counter → Token Transfer →
  Restaurant Review) each larger than the last, then a "build your own" capstone
  with reduced hand-holding — a classic fading-scaffold arc.
- **Time-budgeted lessons:** each section carries an explicit minute budget,
  signalling expected time-on-task (a cadence affordance most written courses lack).
- **Capstone as proof-of-learning:** the final section is a single lesson that hands
  the build back to the learner ("Build Your Final Project").

## Table of contents (5 sections, 22 lessons, ~6h)

### Section 01 — General Information (6 lessons, ~96 min)
1. Course introduction
2. Solana introduction
3. Solana smart-contract fundamentals — Transactions
4. Solana smart-contract fundamentals — Instructions
5. Solana smart-contract fundamentals — Accounts
6. Solana smart-contract fundamentals — Program Derived Addresses (PDAs)

### Section 02 — Project 1: Counter (5 lessons, ~80 min)
Guided build of a counter program (first end-to-end program; state + instructions).

### Section 03 — Project 2: Token Transfer (3 lessons, ~48 min)
Guided build introducing SPL token transfer flows.

### Section 04 — Project 3: Restaurant Review (7 lessons, ~112 min)
Largest guided project — richer account modelling, the "capstone-sized" guided build.

### Section 05 — Build Your Final Project (1 lesson, ~16 min)
Independent capstone: learner designs and ships their own program with minimal
scaffolding.

## Cadence read
Total ~6h video → if paced at the platform's implied section budgets, a
~2-week evening cadence (≈30–45 min/session) completes it. Time budgets per section
are the primary cadence lever; there is no weekly-cohort structure — it is fully
self-serve.
